# 🎯 Hit The Octocat

The first version of a simple Pygame CE clicking game.

## Features

- Click the Octocat to score points.
- The Octocat moves to a random position after each click.
- Score is displayed on the screen.
- The game ends after reaching 5 points.

## Run

```bash
python main.py
```

## Requirements

- Python 3.x
- Pygame CE

```bash
pip install pygame-ce
```
