# 📀 Pygame Screensaver

A simple DVD-style screensaver made with Pygame.

## Features

- Bouncing rectangle animation.
- Bounces around the screen at 22 FPS.
- Displays the supplied logo image in its original colors.
- Clean, function-based code structure.

## Run

```bash
python main.py
```

## Requirements

- Python 3.x
- Pygame 2.6.1

```bash
pip install -r requirements.txt
```

## Notes

This is the first version of the screensaver. Future updates will replace the rectangle with a DVD logo and add background color changes on every bounce.
